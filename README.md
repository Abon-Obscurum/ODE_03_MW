# ODE 3 — JavaFX Media Library

Coursework exercise for ODE (FH Technikum Wien, SS 2026).

A "Media Library" GUI built with Scene Builder. Layout only, no logic.

https://github.com/Abon-Obscurum/ODE_03_MW

## Stack

- Java 17
- JavaFX 21
- Maven
- FXML + Scene Builder

## Structure

```
src/main/java/com/example/demo1/
  Launcher.java           entry point
  HelloApplication.java   stage setup
  HelloController.java    controller
src/main/resources/com/example/demo1/
  hello-view.fxml         the GUI
```
